## 📌 Descripción

Sistema de Información desarrollado para la **gestión integral de una tienda de accesorios para celulares**, permitiendo administrar inventario, ventas, compras y generar reportes detallados para una mejor toma de decisiones.

El sistema cuenta con una interfaz moderna, intuitiva y elegante, diseñada para optimizar la experiencia del usuario y mejorar la eficiencia operativa del negocio.

---

## ✨ Características Principales

✔️ Gestión completa de inventario  
✔️ Registro y control de ventas  
✔️ Administración de compras y proveedores  
✔️ Generación de reportes dinámicos  
✔️ Panel de control con métricas clave  
✔️ Interfaz moderna y responsiva  

---

# 📦 Módulos del Sistema

## 🗂️ 1. Gestión de Inventario

- Registro de productos
- Control de stock
- Actualización de precios
- Categorización de productos
- Alertas de stock mínimo
- Reporte de inventario disponible

---

## 💰 2. Gestión de Ventas

- Registro de ventas
- Generación de facturas
- Cálculo automático de totales
- Control de métodos de pago
- Historial de ventas
- Reportes de ventas diarias, mensuales y anuales

---

## 🛒 3. Gestión de Compras

- Registro de compras a proveedores
- Control de órdenes de compra
- Actualización automática de inventario
- Historial de compras
- Reportes de compras por proveedor

---

## 📊 4. Reportes y Estadísticas

- Reporte de productos más vendidos
- Reporte de ingresos
- Reporte de stock
- Reporte de compras realizadas
- Exportación de reportes en PDF/Excel
